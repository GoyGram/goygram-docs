# Миграция и совместимость

Используйте публичный объект `GoyGram` и объекты событий. Не завязывайтесь на внутренние поля транспорта и диспетчера.

## Методы

Bot API вызывается в `snake_case`:

```python
await app.send_message(chat_id=123, text="Привет")
await app.get_me()
```

MTProto использует `mt_`:

```python
await app.mt_messages_get_history(peer="me", limit=10)
```

Не рассчитывайте на отдельные сгенерированные классы для каждого метода. Методы Bot API динамические, а MTProto-методы берутся из TL-схемы.

## Сессии

Не меняйте `session_name` без причины: другое имя означает другой vault. Перед переносом проверьте права на файл и сохраните резервную копию.

Для production закрепляйте проверенную версию GoyGram и проверяйте raw MTProto-вызовы после обновлений Telegram.
