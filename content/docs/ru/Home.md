# ГойГрам

GoyGram — это асинхронная библиотека Python для ботов Telegram и пользовательских ботов MTProto. Один объект приложения предоставляет общую модель событий, составные фильтры, динамические вызовы API ботов и необработанные вызовы MTProto.

Текущая документированная версия: **0.7.15**. Для пакета требуется Python 3.11 или новее.

## Выбрать транспорт

- **API бота** — введите `bot_token`; используйте методы Telegram Bot API и получайте обновления бота путем длительного опроса.
- **MTProto** — передать `api_id` и `api_hash`; аутентифицировать учетную запись пользователя Telegram и получать обновления MTProto.
- **Оба** — настраивайте оба транспорта только при необходимости. Добавьте к идентификатору чата префикс `bot:` или `mt:`, чтобы выбрать транспорт для помощников, которые принимают идентификатор чата.
